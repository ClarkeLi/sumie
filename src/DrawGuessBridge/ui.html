    手动启动绘制服务

    插件通常会自动启动；如果失败，在终端运行：

    python client/studio_server.py

    端口和路径可在 com.clarke.drawguess.bridge.cfg 的 [Studio] 段修改。服务只监听 127.0.0.1。
